\#Diseño y análisis de un eje mecánico



Herramienta desarrollada en Python para realizar el análisis

mecánico preliminar de ejes sometidos a flexión y torsión.



\#Funciones



\- Cálculo de torque.

\- Cálculo de reacciones.

\- Diagramas de momento flector.

\- Cálculo de esfuerzos.

\- Cálculo del factor de seguridad.

\- Dimensionamiento del diámetro del eje.
